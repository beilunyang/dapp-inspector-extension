# Screenshots

Drop PNGs here to populate the README hero grid. Expected filenames (keep them
consistent with what `/README.md` references):

| File           | Suggested capture                                                          |
| -------------- | -------------------------------------------------------------------------- |
| `panel.png`    | The DevTools panel with a few captured calls + the detail pane selected.   |
| `detail.png`   | A single call's detail view, showing params / result / timing tabs and the Replay / Mock / Block buttons. |
| `options.png`  | The Options page open on the Mock or Block & Throttle section with a rule in the list. |
| `popup.png`    | The extension popup (click the toolbar icon) showing session status + monitoring toggle. |

Tips:

- Use Chrome at 100% zoom and DevTools docked-right for `panel.png` / `detail.png` so the panel occupies ~900–1200 px wide.
- Keep the content PG-rated — nothing in screenshots should reveal private keys, wallet addresses, or internal URLs.
- PNGs render crisper than JPGs for UI; target ≤ 400 KB each.
